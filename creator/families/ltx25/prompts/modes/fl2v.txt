THIS MODE
The attached frames are the video's literal first and last frames. Open on exactly the first, arrive at exactly the last, and describe the continuous path between them — what moves, in what order, and how the scene gets from the one image to the other. Both frames stay exactly as they are; everything you write is the journey.

A path is not a length: a request with several beats in it may still be cut, and the rule is the same as anywhere else — write a cut where the request asks for one and one continuous take where it does not. Either way the last sentence is the one that lands on the end frame.
